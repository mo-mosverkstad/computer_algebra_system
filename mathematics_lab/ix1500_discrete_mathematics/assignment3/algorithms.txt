3. Solovay–Strassen Primality Test
n odd prime, a relative prime to n, a^((n-1)/2) = (a/n) (mod n)
(a/n): Legendre symbol/Jacobi symbol
(a/n) = (a/p_1)^e_1*(a/p_2)^e_2*...*(a/p_n)^e_n
(a/n) = -1: definitely 

random a, 2<=a<=n-2
d = gcd(a, n) = 1, otherwise n composite
j = (a/n) (jacobi symbol calculation)
r = a^(n-1)/2
j == r (mod n) -> pass round, otherwise composite

Factorization Algorithms

1. Fermat's Factorization Method
x^2-y^2 = (x+y)*(x-y)

odd N, smallest x >= sqrt(N)
b^2 = x^2 - N, check b^2 perfect square, if not, x=x+1

N=5959, sqrt(N)=77.19 -> x=78
x=78: 78^2-5959 = 125
x=79: 79^2-5959 = 282
x=80: 80^2-5959 = 441 -> x=80, y=21

2. Pollard's Rho Algorithm
f(x) = x^2+c
x_(i+1) = f(x_i) (mod n)
if x_i = x_j (mod p) -> |x_i-x_j| = p*n, d = gcd(|x_i-x_j|, n)
d is a factor

|x_i-x_j| means check every pair -> tortoise/hare implementation
slow: x_i, fast: x_j, d = gcd(|slow-fast|, n)
