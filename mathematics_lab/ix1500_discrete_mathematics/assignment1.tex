\begin{abstract}

This report presents the solution to constrained enumeration problems of Project 1. The enumeration of subsets must satisfy several constraints, including the sums, parity and product divisibility of the subset elements without enumerating all possible sets. The first problem is small enough to be calculated mathematically by hand using a simple algorithm, while the second two are solved computationally for larger number set. The implemented enumeration exploits the given constraint algorithms to reduces number of enumeration.

\end{abstract}

\section*{Introduction}

The purpose of this project is to find and analyze the subsets that satisfy a number of given arithmetical constraints, including the sums, parity and product divisibility of the subset elements, from a given universal set $U$. This should be done without enumerating through all possible subsets from universal set.

The project consists of three parts: one hand-solved problem for a small universal set and two computational problems of increasing size of universal set. The hand-solved problem provides the fundamental intuition for constrained enumeration algorithm that reduces the search space, while the computational ones are for apply the intuition into code and optimize it as well.

\section*{Assignment 0: Solve by Hand}

For the first solve-by-hand assignment, let the universal set $U$:
\[
U = \{1,2,3,4,5,6,7,8,9\}.
\]
All subsets $S \subseteq U$ must satisfy the element number constraint:
\[
|S| = 4,
\]
and
\[
|E(S)| = 2
\quad\text{or}\quad
|O(S)| = 2,
\]
where
\[
E(S) = \{x\in S : x \text{ is even}\},
O(S) = \{x\in S : x \text{ is odd}\}.
\]
as well as element sum constraint:
\[
\sum_{x\in S} x = 20,
\]
In addition, the product of element
\[
\prod_{x\in S}x
\]
must be divisible by $24$, which forms the dividablity constraint.

These requirements mean that the subset must contain four different elements chosen from the universal set. Since the subset contains four elements, the condition that exactly two of the elements are even, or exactly two of the elements are odd, implies that the subset must contain exactly two even elements and two odd elements. This is because a non-even number is an odd number and a non-odd number is an even number. Therefore, the subset can be divided into two parts with each partial sum: one even part containing two even elements and one odd part containing two odd elements.

Therefore, according to the sum constraint, the total sum of the subset must be $20$, if the partial sum of the even part is $s_E$ and odd part $s_O$
\[
s_E + s_O = 20.
\]

Additionally, the divisibility requirement can be fulfilled by requiring the product of all elements in a valid subset having at least three factors of $2$ and at least one factor of $3$.
\[
24 = 2^3 \times 3,
\]

\subsection*{Algorithm}

A simple method for enumerating the subsets satisfying the element number and sum constraints is to vary the sum of the even part and determine the corresponding required sum for the odd part. For instance, the even part may have the sum of 10, giving the combinations: $\{2, 8\}$ and $\{4, 6\}$. The odd part must then have the sum $10$, resulting in combinations: $\{1, 9\}$ and $\{3, 7\}$. Concatenating both parts, 4 total combinations can be formed: $\{1, 2, 8, 9\}$, $\{2, 3, 7, 8\}$, $\{1, 4, 6, 9\}$ and $\{3, 4, 6, 7\}$. The full enumeration process is listed in Table~\ref{tab:sums}.
